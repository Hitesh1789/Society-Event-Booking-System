# Society Event Booking System

**Society Event Booking System** is a **frontend web application** designed to help users manage societies, view and participate in events, create event drafts by leads, and approve events by president through a **simple, user-friendly interface**.  

This project is built with **React**, **TailwindCSS**, **Radix UI components**, and **Redux Toolkit**, providing a modern and responsive experience.

---

## 🔹 Features

- **User Features:**
  - View all events and societies.
  - Check event details, location, date, and registration status.
  - Register and cancel registration for events.
  - Submit feedback and ratings for events.

- **Society Lead Features:**
  - Create **Event Drafts** for approval.
  - Update or cancel drafts.
  - Track draft history and event approvals.

- **Society President Features:**
  - Approve or reject event drafts.
  - View registered users for each event.

- **Admin/All Users:**
  - Smooth navigation using **React Router v7**.
  - Notifications for actions (e.g., feedback submission, draft creation) using **Sonner**.

- Fully **responsive UI** with **TailwindCSS**.
- Modern component library with **Radix UI** for dialog, select, tooltip, badges, and more.

---

## 🔹 Tech Stack

- **Frontend:** React 19, React DOM
- **State Management:** Redux Toolkit
- **Routing:** React Router DOM
- **Form Handling:** React Hook Form
- **UI Components:** Radix UI, Lucide React Icons
- **Styling:** TailwindCSS, Tailwind Merge
- **HTTP Requests:** Axios
- **Animations & Alerts:** Sonner, tw-animate-css
- **Bundler & Dev Tools:** Vite, ESLint
